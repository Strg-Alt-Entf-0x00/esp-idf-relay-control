Arbitrary Multi-Channel Architecture

This studio supports any custom relay configuration from 1 to 16 channels. You can dynamically add channels via the + icon button, remove channels, assign custom hardware GPIOs, and set aliases.

CLI Protocol Reference

Commands transmitted over Web Serial (115200 Baud, 8N1):

  • on <channel>: Energizes relay channel (e.g. on 0).
  • off <channel>: De-energizes relay channel (e.g. off 0).
  • toggle <channel>: Inverts the relay state.
  • pulse <channel> <duration_ms>: Energizes relay for specified milliseconds, then auto de-energizes.
  • stop <channel>: Aborts an active pulse on a channel.
  • all_off: Emergency master cutoff, resets all channels immediately.
  • status: Queries live state and remaining pulse time for all channels.
  • list: Lists all configured channels with assigned GPIOs and polarity.

Active HIGH vs Active LOW Polarity

Standard optocoupled relay modules usually require Active LOW triggering (driving GPIO low energizes relay). Transistor or MOSFET drivers use Active HIGH. Configure each channel's polarity to match your hardware.
